# PNG 의상 제작 키트

1. `reference/base-reference-1206x2622.png`를 그림 프로그램에 열고 참고 레이어로 둔다.
2. 만들 옷에 맞는 `starter/short-sleeve`, `starter/long-sleeve`, `starter/skirt` 폴더를 복사한다.
3. `art/`의 빈 PNG 또는 같은 크기의 새 레이어에 각 파츠를 그린다. 캔버스와 위치를 유지한다.
4. 각 파츠의 실루엣을 `zones/`에 복사하고 아래 세 색으로 채운다. 원화와 영역 지도는 섞지 않는다.
5. 완성한 옷을 인형에 입힌 모습에 필요한 빨간 연결 표식을 남겨 `attachment-guide.png`로 저장한다.
6. `notes.txt`의 의상 ID·이름·예외를 적고 그 폴더를 ZIP으로 보낸다.

| 색 | 역할 |
|---|---|
| 초록 `#22C55E` | 해당 파츠 규칙에 따라 체형을 따르는 영역 |
| 파랑 `#3B82F6` | 체형 변경 때 크기·모양을 보존하는 영역 |
| 노랑 `#FACC15` | 초록에서 파랑으로 변형을 부드럽게 잇는 영역 |
| 빨강 `#EF4444` | 전체 연결 가이드의 부착점·관절·허리선. 영역 이미지에는 넣지 않는다 |

## 파일 안내

- `reference/`: 기준 인형, 관절 오버레이, 연결 표식 참고 이미지.
- `starter/`: 원화와 영역 지도가 비어 있는 작업 폴더. 반팔 3장, 긴팔 5장, 치마 2장이다.
- `examples/basic-white-tee/`: 완성 원화와 대응 영역 지도의 위치·파일명을 보여 주는 반팔 예시.
- `palette.json`: 색상·캔버스·좌우 규칙 기록. 직접 수정할 필요는 없다.

**모든 제작 PNG는 1206×2622이고, 화면 왼쪽=L·오른쪽=R이다.** 오른쪽의 빈 여백도 잘라내지 않는다. `art/`에는 옷만, `zones/`에는 지정한 세 색만 넣는다. 인형·빨간 표식·설명은 `attachment-guide.png`에서만 사용한다.

긴팔은 어깨~팔꿈치와 팔꿈치~손목을 각각 그린다. 양쪽 팔을 한 파일에 묶지 않는다. 팔꿈치에서 각 파츠를 중심 너머 24px씩 연장하는 것을 시작점으로 삼고, 안쪽 절단선은 그리지 않는다. 실제 회전에서 여유를 조정한다.

치마는 `waist_band`와 `skirt` 두 파츠이다. 기본 플레어형은 본체 하나 안에 위쪽 초록·중간 노랑·하단 파랑을 표시한다. 타이트한 치마처럼 하단도 몸에 맞아야 하면 해당 부분을 초록으로 칠한다. 허리띠는 폭은 몸을 따르고 높이는 보존하는 초록 파츠이다. 치마자락의 파랑은 화면에 정지한다는 뜻이 아니다.

원화에 자연스러운 안티앨리어싱을 사용해도 되지만, 영역 지도 안에서는 색을 흐리게 섞지 않는다. 노랑은 그 자체로 전환 구간을 표시하며 50%라는 뜻이 아니다.

빈 작업 파일을 그대로 제출하지 않는다. 예시와 가이드는 자동 가져오기 기능이 아니다. 현재 게임은 반팔 세 파츠를 처리하며, 새로운 의상을 이 규칙대로 받아 연결과 변형을 구현한다.

상세 규칙과 예외는 ZIP 최상위의 `README.md` 또는 [저장소 규격 문서](https://github.com/251312-commits/dress-lab-v2/blob/main/docs/clothing-assets-v1/README.md)를 따른다.

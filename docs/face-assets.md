# 마법룸 얼굴 편집과 눈 이미지 추가

마법룸 → **얼굴**에서 눈 크기, 미간 간격, 눈 색, 눈 모양, 코 크기, 입 크기를 조절한다. 기본값은 원래 눈 크기·간격·색과 기본 코·입이다.

- 크기와 간격은 기본값의 75–125% 범위이다. 화면에는 기본값과의 차이(`−25%`~`+25%`)를 표시한다.
- 큰 눈에서는 두 눈이 겹치거나 얼굴 바깥으로 나가지 않도록 미간 간격을 자동으로 제한한다. 슬라이더와 수치는 실제 적용된 값으로 맞춰진다.
- 색상환은 홍채에만 적용한다. **원래 색**을 누르면 원본 홍채 그림으로 돌아간다.
- **얼굴 초기화**는 얼굴 설정만 되돌린다. 체형, 피부톤, 옷, 케어 진행도는 바꾸지 않는다.
- 얼굴 설정은 방을 이동해도 유지된다. 현재 체형·피부톤과 마찬가지로 새로고침하면 기본값으로 돌아가며, 별도의 고객별 저장은 아직 연결하지 않았다.

## 눈 모양 추가

현재는 실제 그림이 있는 **기본** 한 가지가 표시된다. 새 모양은 다음 이미지 네 장과 카탈로그 항목 하나로 등록한다. 선택 UI는 카탈로그에 맞춰 자동으로 늘어난다.

### 1. 같은 캔버스로 네 장 내보내기

모든 파일은 **1206 × 2622px, 투명 배경 PNG**이다. 양쪽 눈을 한 파일에 담고, 인형을 기준으로 같은 위치에 그린다. 투명 여백을 자르거나 파츠마다 크기·좌표를 바꾸지 않는다.

| 파일 예시 | 내용 |
| --- | --- |
| `Eyes02_Eyelashes.PNG` | 양쪽 눈 외곽선·속눈썹 |
| `Eyes02_Sclera.PNG` | 양쪽 흰자, 홍채가 보일 수 있는 영역 |
| `Eyes02_Pupil.PNG` | 양쪽 홍채와 동공 |
| `Eyes02_Highlights.PNG` | 양쪽 하이라이트 |

기존 눈의 크기와 위치를 기준으로 작업하면 좌표 설정을 재사용하기 쉽다. 각 파일에는 해당 파츠만 담는다. 그림은 `assets/eyes/`에 넣는다. `files/`는 전달용이며, 카탈로그는 실제 사용할 파일 경로를 가리켜야 한다.

### 2. 카탈로그에 등록

`rig/eye-shapes.js`의 `window.DressLabEyeShapes` 배열에 항목을 추가한다. 기존 `eyes01`은 남겨 둔다. 아래 예시는 파일을 준비한 뒤 등록할 형식이다. 파일 없이 미리 추가하면 해당 옵션을 선택했을 때 로딩에 실패한다.

```js
{
  id: "eyes02",                 // 다른 항목과 겹치지 않는 고유 ID
  label: "눈 모양 2",           // 선택 버튼에 표시할 이름
  defaultColor: "#9F2C3E",      // 원본 홍채의 대표 색
  box: { x: 146, y: 729, w: 368, h: 130 },
  eye: { x: 329, y: 796, lidBottom: 844, maxX: 19, maxY: 14 },
  faceBounds: { left: 135, right: 523 },
  sources: {
    sclera: "./assets/eyes/Eyes02_Sclera.PNG",
    pupil: "./assets/eyes/Eyes02_Pupil.PNG",
    highlights: "./assets/eyes/Eyes02_Highlights.PNG",
    eyelashes: "./assets/eyes/Eyes02_Eyelashes.PNG"
  }
}
```

### 3. 그림 크기가 달라지면 좌표 확인

| 설정 | 의미 |
| --- | --- |
| `box` | 두 눈의 모든 파츠가 들어오는 사각형. PNG 파일을 잘라 저장하는 값이 아니라 렌더러가 내부에서 사용하는 범위이다. |
| `eye.x` | 좌우 눈을 나누는 중앙 x좌표. 중앙선이 어느 눈의 그림도 가르면 안 된다. |
| `eye.y` | 시선 추적의 기준 y좌표 |
| `eye.lidBottom` | 깜박일 때 아래쪽을 고정하는 y좌표 |
| `eye.maxX`, `eye.maxY` | 홍채의 좌우·상하 최대 이동량. 흰자 영역에 맞춰 조정한다. |
| `faceBounds` | 눈 외곽을 배치할 얼굴의 가로 범위. 눈 크기와 함께 미간 간격의 안전한 한계를 계산한다. |
| `defaultColor` | 원본 눈 상태에서 색상환에 보여 줄 대표색. 원본 PNG에 이 색을 덮어씌우지는 않는다. |
| `preview` | 선택 사항. 별도 미리보기 이미지 경로. 생략하면 네 파츠를 합성해 버튼에 표시한다. |

새 모양은 네 파츠가 모두 정상적으로 준비된 후 한 번에 교체된다. 파일 경로·캔버스 크기·좌표가 잘못되면 기존 눈을 유지하고 오류를 표시한다. 빠르게 여러 모양을 선택했을 때는 가장 마지막 요청만 적용한다. 새 모양에도 기존의 깜박임·시선 추적·머리 크기·목 길이 변환이 적용된다.

## 코와 입

기본 코와 입은 `rig/face.js`에서 그리는 독립적인 벡터 파츠이다. 원본 Head PNG를 수정하지 않으며, 얼굴과 함께 움직이고 눈 깜박임의 영향을 받지 않는다. 코 중심은 `(328.6, 855)`, 입 중심은 `(328.6, 888)`이다. 케어 제품은 코·입 위에 표시된다.

## 개발용 API와 확인

```js
dressLabFace.getState();
dressLabFace.setState({ eyeSize: 110, eyeSpacing: 95, eyeColor: "#3A8E69" });
dressLabFace.setState({ noseSize: 90, mouthSize: 110 });
dressLabFace.setState({ eyeColor: null }); // 원래 색
await dressLabFace.selectEyeShape("eyes02"); // 등록한 이미지 옵션
await dressLabFace.reset();
```

`getState()`는 간격 제한을 적용한 실제 상태를 반환한다. 눈 색 이벤트는 `dresslab:eye-color-change`이며, 피부톤·의상 염색 이벤트와 분리되어 있다. 얼굴 변경 이벤트는 `dresslab:face-change`이다.

```sh
node tests/eyes-smoke.cjs
node tests/face-customization.cjs
node tests/facial-care-smoke.cjs
```

테스트는 시선 유지·깜박임·레이어 정합·크기와 간격의 극단값·홍채 색 및 투명도·이미지 변경 실패·동시 요청·코와 입의 머리 변환·얼굴 초기화의 범위를 확인한다. 실제 모바일 화면과 새 이미지의 인상은 브라우저에서 별도로 확인한다.

# DRESS LAB V2 · 관절 리그

이 폴더는 17개 투명 PNG 파츠를 위한 **2D 계층형 관절 회전 엔진**이다. 본 게임의 캐릭터 이미지와 UI를 변경하지 않고 동작을 시험하기 위해 분리했다.

## 사용법

1. 사이트를 평소처럼 열면 **모든 회전값이 0°**인 기본 자세가 표시된다.
2. 주소 뒤에 **?rig=1**을 붙이면 개발용 관절 테스트 패널이 나타난다.
   - https://251312-commits.github.io/dress-lab-v2/?rig=1
3. 11개 슬라이더로 관절을 돌리거나 **팔 들기 / 손 흔들기**를 테스트한다.
4. **축 표시**로 현재 관절 중심을 표시하고, **원본 참고그림**으로 `base/Full.PNG`를 반투명하게 겹쳐 비교한다.
5. **기본 자세**로 초기화하고, **포즈 저장**으로 회전값을 담은 JSON을 내려받을 수 있다.

이 테스트 패널은 게임 플레이 기능이 아니다. `?rig=1`이 없으면 표시되지 않는다. 메인 화면의 4개 방·의상 미리보기 UI는 기존대로 유지한다.

## 관절 데이터

`rig.json`에는 다음이 기록된다.

- 기준 캔버스: **1206 × 2622px**, 원점 왼쪽 위
- 회전축: `base/Full.PNG` 파란 원 **11개 중심**
- 관절별 부모 관절, 기본 0° 자세, 최소·최대 회전 각도
- 각 파츠가 따르는 관절 ID

축 좌표는 참고 이미지의 파란색 원 테두리 픽셀을 분석하고 원형 최소제곱 피팅으로 구했다. **소수 첫째 자리까지 반올림한 근삿값**이므로 실제 회전 중 경계가 어긋난다면 `rig.json`의 해당 `x`, `y` 값을 수정하면 된다.

| 축 ID | 중심 좌표 (px) | 연결된 상위 축 |
|---|---|---|
| torso | 328.6, 1166.5 | 없음 |
| shoulderL | 244.3, 1013.2 | torso |
| elbowL | 188.8, 1175.2 | shoulderL |
| wristL | 141.1, 1319.3 | elbowL |
| shoulderR | 412.8, 1013.3 | torso |
| elbowR | 468.6, 1175.2 | shoulderR |
| wristR | 516.4, 1319.2 | elbowR |
| hipL | 257.2, 1367.8 | 없음 |
| kneeL | 246.3, 1623.2 | hipL |
| hipR | 399.4, 1367.7 | 없음 |
| kneeR | 411.0, 1623.2 | hipR |

- **L은 화면 왼쪽**, **R은 화면 오른쪽** 파츠를 뜻한다.
- 머리와 목에는 별도의 회전축이 없다. 두 파츠는 몸통 움직임을 따르지만 개별적으로 돌리지 않는다.
- `Full.PNG`는 일반 렌더링의 파츠가 아니며, 테스트에서 참고 이미지를 선택할 때만 표시한다.
- 파츠 앞뒤 순서는 기존대로 파일명 숫자가 큰 것부터 그리고, **작은 번호가 위에** 온다.
- 0° 자세에서는 모든 이미지를 기존과 같이 `(0,0)`에 그대로 그리므로 원본을 왜곡하지 않는다.

## 코드 구조

- `rig.json`: 축 좌표, 부모-자식 관계, 각도 제한, 파츠별 연결
- `rig.js`: 계층형 2D 회전 렌더러 (Canvas transform/rotate)
- `debug.js`: 테스트 패널, 슬라이더, 예시 포즈, 포즈 JSON 다운로드
- `../index.html`: 캐릭터 이미지 로딩과 렌더러 연결. 리그 로딩 실패 시 기존 정적 합성으로 돌아간다.

## 현재 범위와 한계

**구현됨:** 관절 11개와 파츠 17개의 연결, 독립/상속 회전, 기본 자세 복원, 각도 제한, 테스트용 예시 동작.

**미구현:** 관절 틈새를 자연스럽게 메우는 메시 변형, 동작 키프레임 편집기, 게임 이벤트와 애니메이션 연결, 신체를 따라 움직이는 의상 레이어 시스템.

회전만으로는 팔꿈치나 무릎의 외곽선이 벌어지거나 겹쳐 보일 수 있다. 이 경우 관절용 덮개 파츠, 움직임 각도 제한, 의상 레이어의 추가 리깅 등으로 보완해야 한다. **이미지 자체를 늘려 왜곡하는 기존 V1 방식으로 돌아가지 않는다.**
